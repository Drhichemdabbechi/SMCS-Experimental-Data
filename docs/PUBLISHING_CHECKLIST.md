# Pre-publication checklist

- [ ] Verify each aggregate against the author's actual experiment exports.
- [ ] Confirm that the manuscript and repository use identical original figure series.
- [ ] Confirm copyright and platform-sharing conditions; do not upload raw user-level social-media records without permission.
- [ ] Choose and add a reuse license after coauthor approval (no license is assumed here).
- [ ] Confirm author names, ORCID if desired, citation metadata, and final publication details.
- [ ] Create the GitHub repository, push this repository root, and check all CSV previews.
- [ ] Update the article's Data and Code Availability statement with its **actual URL**.
- [ ] If required by the journal, deposit additional original experiment logs or scripts separately after verification and permissions review.
